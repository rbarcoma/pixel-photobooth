# Arcade Classic

Arcade Classic by Jakob Fischer is installed locally as `arcadeclassic.ttf`.
Major website headings and the photo composition title use this font.
Body text, navigation, controls, smaller titles and export captions use DM Sans,
loaded from Google Fonts, with a sans-serif fallback.

Source: https://www.1001fonts.com/arcadeclassic-font.html
Original license: `pizzadudedotdk.txt` (included unchanged).

The author permits non-commercial use only and restricts redistribution. The
font binary is excluded from Git; obtain permission before commercial use or
redistributing it in a public deployment. For a fresh checkout, download your
own permitted copy and save the TTF as `public/fonts/arcadeclassic.ttf`.

Pixel headings use monospace if the file is unavailable or a glyph is unsupported.
